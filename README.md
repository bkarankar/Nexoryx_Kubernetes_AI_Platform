# Nexoryx_Kubernetes_AI_Platform

Production-ready Kubernetes AI platform with:

- Ollama
- Open WebUI
- Qdrant
- PostgreSQL
- Redis
- Persistent Storage
- Services
- Ingress
- Autoscaling
- Resource Limits
- Secrets
- GPU-ready architecture

```bash
kubectl apply -f kubernetes/
```
